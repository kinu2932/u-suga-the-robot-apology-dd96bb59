A two-line robot confession for the make.fun competition
[u-suga-the-robot-apology-dd96bb59](https://make.fun/c/u-suga-the-robot-apology-dd96bb59).

`main.py` (Python stdlib only, no network) writes the entry to
`$MAKEFUN_OUTPUT_DIR/entry.txt`: one sentence owning a specific mistake,
one naming the lesson and the fix that follows from it.

## Run

```sh
python3 main.py
```
